# SysSync (اسم داخلي فقط - التطبيق يظهر باسم "أدوات النظام")

تطبيق أندرويد يفتح تليغرام وإنستغرام داخل WebView، ويفحص الصفحة كل 15 دقيقة
بحثًا عن رسائل جديدة، ويرسل إشعار أندرويد عند وجودها.

## ملاحظة: التمويه

هذا التطبيق مموّه بالكامل بحيث لا يظهر أي شيء يكشف علاقته بتليغرام/إنستغرام:
- **اسم التطبيق**: "أدوات النظام" (بدل أي اسم يذكر الرسائل)
- **الأيقونة**: أيقونة ترس رمادية عامة (بدل شكل مغلف)
- **اسم الحزمة الداخلي**: `com.example.syssync` (بدل أي اسم يذكر messenger)
- **نصوص الواجهة**: "تحديث 1 / 2"، "البحث عن تحديثات"، "آخر تحديث" — بدون ذكر أي منصة أو كلمة "حساب"
- **الإشعارات**: عنوان "تحديث جديد" ونص عام "عنصر جديد بانتظار المراجعة"،
  وأيقونة الإشعار مزامنة عامة بدل أيقونة رسالة

### سلوك الأزرار (تمويه إضافي)

زرّا "تحديث 1" و"تحديث 2" لهما سلوكان مختلفان حسب طريقة الضغط:

- **ضغطة عادية (tap)**: تفتح شاشة "إعدادات التحديثات" — شاشة عامة فيها مفتاحين
  (تحديث تلقائي / إشعارات) لا تكشف شي، وهذي الشاشة اللي بتظهر لأي حد يجرب
  يضغط الأزرار بشكل عابر
- **ضغطة مطوّلة (long press)**: تفتح فعليًا صفحة تسجيل الدخول (WebView) للموقع
  الحقيقي (تليغرام أو إنستغرام حسب الزر) — هذي الوظيفة الحقيقية، ومخفية خلف
  الضغط المطوّل فقط

## كيف يعمل

- **تليغرام**: يقرأ عدد الرسائل غير المقروءة في المحادثات **الخاصة فقط** (يتجاهل
  المجموعات والقنوات) من `web.telegram.org/k`.
- **إنستغرام**: يكتشف فقط **وجود** رسالة مباشرة جديدة (بدون رقم دقيق) من
  `instagram.com/direct/inbox`.
- الفحص يتم عبر **WorkManager** كل 15 دقيقة (الحد الأدنى الذي يسمح به أندرويد
  لأي periodic work) — بدون إشعار دائم بشريط الحالة.
- تسجيل الدخول يتم مرة واحدة يدويًا من داخل التطبيق (زر "تسجيل الدخول")، وتُحفظ
  الجلسة عبر الكوكيز، فلا تحتاج تسجّل الدخول كل مرة.

## ⚠️ تنبيه مهم جدًا

الكود يعتمد على قراءة عناصر HTML محددة (CSS selectors) من صفحتي تليغرام
وإنستغرام كما هي **الآن**. هذين الموقعين يغيّران تصميمهما بشكل دوري، لذا:

- من المتوقع أن تحتاج نتفحص الفحص أول مرة على جهاز حقيقي، ونتأكد إن كان
  السلكتورز في `Constants.kt` (`TELEGRAM_JS` و `INSTAGRAM_JS`) تطابق فعليًا
  الرقم/النقطة الصحيحة.
- إذا توقف الفحص عن العمل يومًا ما (مثلاً بعد تحديث تصميم الموقع)، الحل هو
  فتح صفحة الموقع من متصفح الكمبيوتر (F12 → Elements)، والبحث عن العنصر
  الجديد الذي يحمل رقم/علامة الرسائل غير المقروءة، وتحديث الـ selector.

### تليغرام: يعتمد على فولدر "Contacts"

بدل محاولة تخمين أي محادثة "شخصية" وأيها مجموعة/قناة، الكود يقرأ عداد غير
المقروء من **تبويب الفولدر المسمى "Contacts"** في أعلى قائمة المحادثات
بتليغرام ويب — نفس الفولدر اللي أنشأه المستخدم بنفسه ليحتوي فقط على جهات
اتصاله الشخصية. هذا يعني:

- **لازم يكون فولدر باسم "Contacts" (بالإنجليزي بالضبط) موجود فعليًا في
  حساب تليغرام قبل ما يشتغل الفحص**، وإلا الكود يرجع `ERROR:folder_not_found`
- اسم الفولدر قابل للتعديل من `Constants.TELEGRAM_FOLDER_NAME` لو غيّرت اسمه
  لاحقًا

## البناء عبر Termux

```bash
pkg install openjdk-17 gradle git -y
cd /storage/emulated/0/Download/syssync
git init
git config --global --add safe.directory $(pwd)
git add .
git commit -m "initial scaffold"
gradle assembleDebug
```

الـ APK الناتج يكون في: `app/build/outputs/apk/debug/app-debug.apk`

## البناء عبر GitHub Actions

بعد رفع المشروع لمستودع GitHub (فرع `main`)، الـ workflow
`.github/workflows/build.yml` يبني الـ APK تلقائيًا ويرفعه كـ Artifact
باسم `syssync-debug-apk`.

## أول تشغيل

1. افتح التطبيق، **اضغط ضغطة مطوّلة (long press)** على زر "تحديث 1" وسجّل
   دخولك لتليغرام عبر رقم الجوال داخل الـ WebView.
2. ارجع، **اضغط ضغطة مطوّلة** على زر "تحديث 2" وسجّل دخولك لإنستغرام بنفس
   الطريقة.
3. اضغط "البحث عن تحديثات الآن" لتجربة الفحص يدويًا والتأكد إن الإشعارات
   تشتغل.
4. بعدها الفحص التلقائي يشتغل كل 15 دقيقة تلقائيًا بالخلفية.

> ملاحظة: الضغطة العادية (tap) على "تحديث 1"/"تحديث 2" تفتح شاشة إعدادات
> عامة (تمويه) بدل صفحة تسجيل الدخول — لازم الضغط المطوّل تحديدًا.
